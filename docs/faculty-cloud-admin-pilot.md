# 教師雲端管理

## 現況

- 教師管理已加入既有 `graduate-course-admin` Cloud Run 服務，沒有建立第二個管理服務。
- 管理入口：`/faculty/`
- 中英文草稿預覽：`/faculty/preview/`
- 正式中文主站與英文站均已讀取本資料，讀取失敗時保留生成時的靜態備援。

## 新增教師流程

- 教師清單右上角的「新增教師」會建立新草稿，預設類別為「合聘教師」。
- 新教師的中文與英文公開狀態預設關閉；先填妥不可重複的網址識別碼與中英文姓名，再建立草稿。
- 首次儲存後才能上傳照片及預覽，網址識別碼也會鎖定，避免公開網址意外變更。
- 公開任一語言前必須具備照片及該語言職稱；缺漏時發布會被阻擋，但隱藏中的草稿可先保存。
- 新教師若沒有既有靜態頁網址，中文及英文站會導向以 `?id=` 載入的通用個人頁。

## 資料分層

- 草稿及備份：私有 bucket `gs://ntujour-faculty-admin-private/faculty-pilot/v1/`
- 公開資料：`gs://ntujour-graduate/faculty-pilot/v1/`
- 公開版以 `current.json` 指向不可變的 release 目錄；中英文資料在所有檔案上傳完成後一起切換。
- 教師名單只有卡片欄位；完整介紹與著作依教師、語言分檔。

## 保護措施

- 草稿儲存及發布都使用版本條件，拒絕以舊頁面覆蓋新資料。
- 每次覆寫草稿前建立獨立備份；備份失敗時停止儲存。
- 公開資料不包含原始匯入資料或管理欄位。
- 介紹內容發布前移除可執行標記；外部網址只接受 HTTP 或 HTTPS。
- 教師資料路徑與課程、指導學生、活動及系友資料分離。
